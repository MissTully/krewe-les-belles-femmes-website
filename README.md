# Krewe of Les Belles Femmes

Public digital home for the 25th year. Front Stage is cream playbill. Stage Door is velvet and stays locked until January 2027.

## Run it on your computer

You need Node.js 20 or newer.

```bash
npm install
npm run dev
```

Open the address Vite prints, usually `http://localhost:5173`.

## What ships in October

- Home with motto and two ticket buttons
- Heritage, Fellowship, Giving Back
- Silver Soirée interest form
- Apply to Join
- Underwriters program
- Stage Door placeholder

Forms save nothing to a server yet. That is on purpose. Paid tickets and member login wait for official email, roster, and a processor the treasurer accepts.

## What must not land on the home

Generated showgirl faces. Official Paris nightclub marks. Personal Venmo for dues.

## Stack

Vite, React, TypeScript. Styles live in `src/index.css` as named color tokens. No database in this phase.
